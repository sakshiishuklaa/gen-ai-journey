# GENERATIVE-AI-FUNDAMENTALS

* Generative AI means generating new data or meaning on its own.
* Every model has its own tokenisation process to produce tokens for the input.
* Based on that tokenisation, it predicts or generates the result by analysing the token patterns.
* LLM's are Large Language Models that are AI systems that can understand and generate human language by processing various data.
* GPT stands for generative, pre-trained, transform model.
* LLMs main mechanism is prediction and generate answers based on learn patterns.
* As a pure LLM without external help it cannot tell live temperature as it it not present in its training data.
